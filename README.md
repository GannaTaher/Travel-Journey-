
# ✈️ Travel Journey
### AI & Logic Programming Project — ITI 2025

> A Prolog-based trip planning application that finds all possible routes between Egyptian cities using available transportation modes — with an interactive graphical interface.

---

## 📌 Overview

Travel Journey is a smart route-planning system built entirely in **Prolog**. The user selects a starting city and a destination, and the system searches through all available transportation options to find every possible route — direct or indirect.

The program uses a **logic-based database** of cities and transport connections, combined with **recursive Prolog rules** to explore all paths. If multiple routes exist, it displays all of them. If no route is available, it clearly tells the user.

---

## ⚙️ How It Works

1. **User selects** a starting city and a destination city via a graphical interface
2. **Prolog rules** search through the database recursively — trying direct and multi-stop routes
3. **All valid routes** are displayed clearly, showing each city and the transport used
4. If no route is found, the system returns a **"destination not reachable"** message
